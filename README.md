# Ketology — продуктовый лендинг

Статическая страница без сборки: один `index.html` с инлайновым CSS + папка `assets/`.
Деплой — GitHub Pages из ветки `main`.

## Источник дизайна

Figma: `Ketology_product_LP`, файл `f0sO9fZ9FdiYG2QWRdAj1a`, нода `495:248` (фрейм «Ketology», 1440×7666).
Тексты, цвета, размеры и отступы сняты из Figma REST API, не на глаз.

Ассеты выгружены через `/v1/images` в PNG@2x и сконвертированы в WebP (16.7 МБ → 1.1 МБ).

## Структура

```
index.html        вся страница + CSS в <style>
assets/*.webp     фотографии, паки, иконки, логотипы
assets/logo-ketology.svg
```

## Локально

Открыть `index.html` в браузере — сборка не нужна.

## Известные расхождения с макетом

- **Шрифт.** В макете Gerbera (коммерческий, в вебе нет). Подставлен Onest с Google Fonts —
  ближайшая геометрическая гротеска с кириллицей. Метрики отличаются, длины строк поедут.
- **Шапка и подвал** в макете лежат растром (ноды `495:253`, `495:500` — скриншоты сайта
  siberianwellness.com). Вставлены картинками как есть, не свёрстаны.
- **Нода `495:298`** (`image 38`, 586×586) не отдалась экспортом Figma — вернулся `null`.
  На странице её нет.
- **Текст «Почему большинство диет заканчиваются срывом?»** (нода `495:251`) в макете лежит
  поверх блока состава и перекрыт им. На странице не выведен — нужно решение дизайнера.
